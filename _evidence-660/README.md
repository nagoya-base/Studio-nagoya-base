# #660 作品切替のスクロール距離（証跡）

## 設計
- 1作品＝閲覧可能高（`--pv-vh`＝`100svh`、非対応は`100vh`）の70%。行は4行＋キャプションのない**末尾行**（`--pv-row/2 + 写真高/2`）で、写真は5行ぶんを`position: sticky`で支える（4枚目の後も固定が続く）
- 表示作品は「固定された写真の縦中央より上にある最後のキャプション」。`scroll`／`resize`／`orientationchange`／`load`→`requestAnimationFrame`で現在位置から再計算（IntersectionObserver不使用）
- キーボード／クリックの手動選択は、ホイール・タッチ・スクロール系キー（↑↓PageUp/Down/Home/End）まで位置判定で上書きしない（Tabでは解除しない）
- `.is-active`のときだけ行高さ・変数が効く。JS無効・reduced-motionは従来の静的4作品一覧（確認済み: sticky・非表示・演出用余白なし）

## 計測（Chromium、`measure-scroll.js`。ローカルでJekyll include抜きの静的ビルド＝固定ヘッダーなし）

| PC 高さ800 | 4658 | 5206 | 5766 | 6326 | 6899 | 548 / 560 / 560 / 573 |
| PC 高さ900 | 4658 | 5310 | 5938 | 6570 | 7264 | 652 / 628 / 632 / 694 |

- 滞在距離は高さの約65〜95%。1枚目＝固定開始→2枚目、4枚目＝4枚目→固定終了。横スクロールなし
- 写真は縦方向でなく列幅で決まる大きさ（PC 591px・SP 207／263px）で、従前と同じ。小さくしていない
- `shots/`: 各ビューポートの固定開始・各作品・固定終了・終了後の連続画像

## 挙動（`check-behavior.js`）
大ジャンプ（帯の飛び越し）・逆方向・resize（800→900）でも位置に合う作品へ追いつく。手動選択4はスクロール位置が作品1でも保持され、wheelで位置判定へ復帰。
