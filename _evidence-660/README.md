# #660 作品切替のスクロール距離（証跡）

## 設計
- 1作品＝閲覧可能高（`--pv-vh`＝`100svh`、非対応は`100vh`）の70%。行は4行＋キャプションのない**末尾行**（`--pv-row/2 + 写真高/2`）で、写真は5行ぶんを`position: sticky`で支える（4枚目の後も固定が続く）
- キャプションは写真の縦中央でsticky固定。表示作品は「固定位置まで上がってきた最後のキャプション」（先の固定済みキャプションは`.is-past`で隠す）。`scroll`／`resize`／`orientationchange`／`load`→`requestAnimationFrame`で現在位置から再計算（IntersectionObserver不使用）
- キーボード／クリックの手動選択は、ホイール・タッチ・キャプション以外の押下（スクロールバーのドラッグ／トラッククリック）・スクロール系キー（↑↓PageUp/Down/Home/End）まで位置判定で上書きしない（Tabでは解除しない）
- `.is-active`のときだけ行高さ・変数が効く。JS無効・reduced-motionは従来の静的4作品一覧（確認済み: sticky・非表示・演出用余白なし）

## 固定ヘッダー回避（`check-header.js`、`header-shots/`）
各作品の区間で、写真上端（PC128／SP116px）は固定ヘッダー＋予約バナー下端（PC111／SP105px）より下、現在のキャプションは画面内（写真の縦中央に固定）。全ビューポート・全作品で true。
なお初版は現在のキャプションが区間の後半で画面外（ヘッダーの下）へ流れていたため、キャプションをsticky固定し、写真の実測高を`--pv-ph`で渡して固定位置と末尾行を合わせた。

## 挙動（`check-behavior.js`）
大ジャンプ（帯の飛び越し）・逆方向・resize（800→900）でも位置に合う作品へ追いつく。手動選択4はスクロール位置が作品1でも保持され、wheelで位置判定へ復帰。
