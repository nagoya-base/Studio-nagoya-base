## SNB（Studio Nagoya Base）

会員 / 非会員で部屋料金が異なる。**一般料金は現行のまま据え置き**（Issue #475。値上げの表示・告知はしない）。MEMBER料金は現行会員料金。

| 時間 | 一般 平日 | 一般 土日祝 | MEMBER 平日 | MEMBER 土日祝 | 差額 |
|---|---:|---:|---:|---:|---:|
| 1時間 | 2,000円 | 2,500円 | 2,000円 | 2,500円 | 0円 |
| 2時間 | 4,000円 | 5,000円 | 4,000円 | 5,000円 | 0円 |
| 3時間 | 6,000円 | 7,500円 | 5,500円 | 7,000円 | 500円 |
| 4時間 | 8,000円 | 10,000円 | 7,000円 | 9,000円 | 1,000円 |
| 延長 +1時間 | 2,000円 | 2,500円 | 1,500円 | 2,000円 | 500円 |

- SNB MEMBER: 月額500円（税込）。Stripeで自動更新、毎月1日更新、入会月は日割りなし満額（入会日〜当月末）、日割り返金なし。
- 解約は`/membership/status/`の専用UI（本人確認後）で受付。UIを使えない場合は予約フォーム等でも受付。次回の更新前に解約処理が完了した場合は次回以降の自動更新を停止する。締切日は設けていない（設ける場合は別Issueで事業ルールとして決めてから反映する）。解約後も支払済みの月末まで有効。
- 決済失敗の月は猶予なしで資格なし（一般料金）。初回利用者から加入可。旧制度の会員は自動移行しない。
- 会員訴求は「3時間以上の利用で一般料金より安くなる」「3時間利用では一般料金との差額が月会費500円相当」。継続・長時間利用者向けの優遇制度として案内し、「安く使うために会員加入が必要」と受け取られる表現・「2時間以上で会費相当以上の差額」・「1回で元が取れる」は使わない。
- 案内文言は `_includes/membership_terms_ja.html` に1か所で持ち、会員案内ページ・利用規約・特商法が同じ条件を指す。

## 会員限定の特典（#478）

適用開始: **2026/12/1 00:00 JST以降に新規作成された予約・OptionOrder**から。2026/11/30までに作成済みの予約・OptionOrder（`AWAITING_PAYMENT` / `PENDING_APPROVAL` 等を含む）は旧ルールのまま（作成時刻 `createdAt` で判定。承認・決済・日程変更の時点で世代を切り替えない）。マージ即時で旧注文を新ルールへ切り替えない。`STRIPE_CHECKOUT_ENABLED` は変更しない（無効の間は新規加入できないため、新特典を使えるのは既にactual membershipが有効な利用者のみ）。

### 会員資格（共通）

- SNB / SNB mens / Studio X で共通の SNB MEMBER（月額500円）。mens専用・Studio X専用の会員制度・Stripe subscription・Success URLは作らない（加入完了は共通の `/membership/complete.html`）。
- **actual membership（実会員資格）= 利用日の属する月の支払い事実**（`MemberRepository.isMemberForMonth`）。`priceIsMember`・mens経路・価格overrideは実会員資格ではない（混同しない）。mensの通常部屋料金は従来どおり、非会員でもMEMBER相当を維持する。
- 翌月の部屋は通常どおり予約可能。翌月分のペアパック・シャワー・会員限定有料機材は、その月の1日以降、当月会費の決済成功が台帳に反映されてから確定できる（猶予期間なし）。月跨ぎの日程変更は変更先月のactual membershipを再確認し、無ければペアパック・シャワーを維持したままの変更は拒否する。
- Studio Xは「FREE以外は既定で会員必須」のfail-closed設計（未知・将来追加される有料categoryも自動で会員必須。`BookingOptions.orderRequiresActualMember` と `planOrders` の最終防御）。
- 会員資格を再確認する箇所（fail-closed。非会員・利用月不一致・台帳エラーはすべて同一の外部向けエラー `MEMBER_BENEFIT_NOT_AVAILABLE` で拒否）: 予約作成 / OptionOrder作成 / Checkout開始 / 日程変更 / Admin承認 / 0円バンドルの確定 / 管理者の手動確定・EXPIRED復活 / 現地精算（入金記録）の確定。
- 会員照会は既存の資格照会と同じメール単位のレート制限（`opt_elig_`）に載せ、メールアドレスから会員の有無を推測できないようにする。
- 見積りAPI（`estimatePrice`）は会員台帳を照会しない。決済済み（Stripe Webhook）の注文・予約は、後から会員資格不足を理由に拒否・巻き戻ししない。

### 会員限定2名ペアパック（SNB / SNB mens）

| 内容 | 平日 | 土日祝 |
|---|---:|---:|
| 2名ペアパック（3時間・1〜2名） | 5,000円 | 6,000円 |

- 通常料金tier（GENERAL / MEMBER）の置換ではなく、独立プラン `member_pair_3h`（`Bookings.planCode` に保存）。通常の会員3時間料金（5,500円 / 7,000円）とは別商品。
- 3時間が基本（3時間未満は不可）・1〜2名（3名以上はサーバー側で拒否）。他の割引・優待と併用不可。4時間以上へ延ばす場合は、延長分に通常の会員延長料金（平日+1,500円 / 土日祝+2,000円）。
- 日程変更後もプランを保持し、平日⇔土日祝の変更では変更先の曜日区分で5,000円 / 6,000円を再計算する（`FeeCalculator` / `BookingReschedule`）。3時間未満へ短縮するとプラン料金を自動算出できず手動確認が必須（通常料金に化けない）。
- 正本: `BookingPricing.gs`（`PAIR_PACK_`）。表示は `_includes/membership_benefits_ja.html`。

### 会員限定シャワー（SNB / SNB mensのみ。Studio Xでは表示しない）

- 1予約につき1回 1,000円。同一予約の利用者2名まで共有可・予約時間内のみ。OptionOrder系の有料オプション（`category=MEMBER_SERVICE`・`items=['SHOWER']`・Issue #481で事前連絡・管理者承認制に変更: `PENDING_APPROVAL` → 承認 → `AWAITING_PAYMENT` → Checkout決済 → `CONFIRMED`）。正本: `BookingOptions.gs`（`SHOWER_PRICE_JPY_`）。
