背景・テーマと設営オプション

Studio Xトップの「一室で、6つの世界。」を、オプションを選ぶ観点で整理しました。設営はセルフ（無料）が基本で、対応できるものはスタッフ設営（有料・事前確認制）も選べます。

{% include studio_x_worlds_ja.html %}

対応可否・料金・条件は予約フォームのオプションと同じ正本に基づきます。有料機材を使う場合は、設営方法・片付け方法の選択が必要です。

オプションの選び方

背景セット

撮りたい世界に合わせて、上の6テーマから選びます。

照明機材

必要な機材だけを1点ごとに選びます。料金は下の機材一覧のとおりです。

設営方法

セルフ設営（無料）か、スタッフ設営（有料・事前確認制）を選びます。

片付け方法

セルフ片付け（無料）か、スタッフ片付け（有料・事前確認制）を選びます。

有料機材のセルフ利用は、管理者の利用許可を受けた方のみです。有料機材は施錠管理しているため、許可を確認できるまでお支払い・確定はできません。初めての方は先にご相談ください。背景布などの無料備品のセルフ設営に、許可は不要です。

部屋代と有料オプションは別決済です。スタッフ対応は承認後、有料機材は部屋の予約確定後にオンラインで決済します。
