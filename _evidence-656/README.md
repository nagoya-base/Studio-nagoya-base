# #656 照明比較の暖色だけ半幅になる不具合（証跡）

- 原因: SP(≤800px)の `.pv-compare-item:nth-child(5) { width: 50% }`（JSなし5枚一覧用）が、JS切替表示にも効いていた
- 修正: セレクタを `.pv-compare:not(.is-enhanced)` に限定（`styles/mens-preview-633.css` 1行）
- 確認: `check-compare-width.js`（Playwright、ローカルJekyllビルド）。使い方 `node check-compare-width.js <_site> <修正前CSS>`

| 幅 | 修正前（暖色／他色） | 修正後（暖色／他色） |
| --- | --- | --- |
| 320 | 136 / 272 | 272 / 272 |
| 390 | 171 / 342 | 342 / 342 |
| 768 | 360 / 720 | 720 / 720 |
| 800 | 376 / 752 | 752 / 752 |
| 801・1280 | 同幅 | 同幅（変化なし） |

- JS無効時（320〜1280）の5枚一覧の位置・幅は修正前後で完全一致（SPは2列＋最終1枚中央）。横スクロールなし
- 暖色選択時: ボタンの押下状態・キャプション「暖色の照明」・写真拡大（orange画像）を確認
